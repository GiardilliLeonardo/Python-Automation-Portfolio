# Avvio Rapido
1. Assicurati di aver installato le dipendenze necessarie (es. `npm install` o `pip install -r requirements.txt`).
2. Esegui il file principale direttamente da terminale: `node index.js` (oppure `python main.py`).
3. Il programma sarà immediatamente operativo e l'output visibile in console.
