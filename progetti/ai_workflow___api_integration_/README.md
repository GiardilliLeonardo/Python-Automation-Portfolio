# Avvio del Progetto
Assicurati di avere l'ambiente di runtime corretto installato sul tuo sistema.
Apri il terminale in questa directory ed esegui il file con: `[INSERISCI COMANDO QUI]` (es. `python main.py` o `node app.js`).
Il programma si avvierà mostrando l'output direttamente nella console.
