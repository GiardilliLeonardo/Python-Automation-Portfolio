# Avvio Rapido
- **Prerequisiti:** Assicurati di aver installato le eventuali dipendenze (es. `npm install` o `pip install -r requirements.txt`).
- **Terminale:** Apri il prompt o il terminale all'interno di questa cartella.
- **Esecuzione:** Avvia il file digitando il comando appropriato, ad esempio `node index.js` oppure `python main.py`.
